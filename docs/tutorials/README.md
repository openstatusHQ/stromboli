# Tutorials

Tutorials are lessons. Each one takes you from nothing to a working result, one step at a time. Follow them in order and don't skip steps: the point is to get a feel for stromboli, not to cover every option. The options are in the [how-to guides](../how-to/README.md) and the [reference](../reference/README.md).

| # | Tutorial | You will | Time |
|---|---|---|---|
| 1 | [Your first investigation, locally](01-first-investigation.md) | run stromboli on your machine with a demo app, read a brief, and watch an investigation of a fake incident | 20 min |
| 2 | [Connect a real service](02-connect-a-real-service.md) | run stromboli with Docker Compose, connect your own log store, describe one service, and trigger an investigation from an alert webhook | 30 min |
